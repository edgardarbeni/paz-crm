# Colección de ejemplos de la API (Bruno)

Abre esta carpeta en [Bruno](https://www.usebruno.com/) y selecciona el entorno `local`
(`https://localhost`, el Caddy de `docker compose`). Cada fase agrega su carpeta de requests
(D-42). El contrato completo está en `/docs` (Swagger UI) y `/redoc` cuando
`PAZ_API_DOCS_ENABLED=true`.
