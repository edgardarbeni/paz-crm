# D-26 · Régimen municipal

- **Estado:** Aceptada
- **Área:** Candidaturas

Cada municipio tiene, por proceso, un régimen de elección: `party_based` o `normative_system` (sistemas normativos internos). Los de sistemas normativos se excluyen de las planillas. Las alcaldías de CDMX usan el mismo modelo de planilla, con cargos propios del catálogo (alcaldía + concejalías). Nada se precarga sin fuente oficial.
