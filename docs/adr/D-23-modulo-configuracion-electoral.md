# D-23 · Módulo de configuración electoral

- **Estado:** Aceptada
- **Área:** Candidaturas

Por cada proceso se habilita qué cargos van a elección, a nivel federal y a nivel local (por estado). También guarda el número de posiciones, el método de RP ([D-21](D-21-rp-local-configurable.md)) y la configuración municipal ([D-24](D-24-regidurias.md) a [D-26](D-26-regimen-municipal.md)).
